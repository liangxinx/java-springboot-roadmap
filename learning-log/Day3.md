# Java — Day 3 筆記

## Method 建立

想像你在很多地方都要「印出分隔線」，如果每次都要打好幾行 `System.out.println("---")`，很麻煩又難維護。Method 可以把一段程式碼包裝起來，取一個名字，之後要用的時候直接「呼叫」它的名字就好，不用重複打程式碼。

### 基本語法

```java
修飾詞 回傳型態 方法名稱(參數) {
    // 方法內容
}
```
> Method 一定要寫在 class 裡面，但不能寫在另一個 method 裡面。

---

## Parameter 參數

上一節的 `sayHello()` 每次呼叫都做一模一樣的事情。但如果你想要 method 每次執行時可以帶不同的資料進去（例如印出不同人的名字），就需要 **參數（Parameter）**。

### 基本語法

```java
修飾詞 回傳型態 方法名稱(型態 參數名稱) {
    // 可以在裡面使用這個參數
}
```
### 專有名詞小提醒：Parameter vs Argument

- **Parameter（參數）**：method 定義時括號裡寫的東西，例如 `greet(String name)` 裡的 `name`
- **Argument（引數）**：呼叫 method 時實際傳進去的值，例如 `greet("小明")` 裡的 `"小明"`

多個參數用逗號分隔，呼叫時要**依照順序**傳入對應型態的值，順序或型態不對會編譯錯誤。參數是「區域變數」，只在該 method 內部有效。

## Return 回傳值

前面的 method 都是 `void`，執行完就結束，不會把結果「帶回去」給呼叫它的地方。如果希望 method 算完結果後可以**回傳**，讓呼叫端拿去用（存進變數、拿去做別的運算），就要用 `return`。

### 基本語法

```java
修飾詞 回傳型態 方法名稱(參數) {
    return 值;
}
```

`void` 換成實際的資料型態（`int`、`double`、`String`、`boolean`），並且裡面要有 `return` 把值送出去。

### 重要規則

1. **回傳型態要跟 `return` 的值型態一致**（宣告 `double` 就要回傳 `double`）
3. **`return` 一執行，method 立刻結束**，後面的程式碼不會再執行（這點跟 `break` 有點像，但範圍是整個 method）

## Method 呼叫流程

呼叫 method 時，執行順序會**跳到那個 method 裡面**，跑完再**跳回原本呼叫的地方**，繼續往下走。

1. 暫停目前這一行（main 目前執行到的位置會被記住）
2. 跳進去被呼叫的 method，從頭開始執行它的內容
3. 遇到 `return`（或執行完最後一行），跳回去剛剛暫停的地方
4. 如果有 `return` 值，帶著這個值回到呼叫處，繼續往下執行

### Call Stack（呼叫堆疊）

Java 內部是用一個叫 **Call Stack** 的機制記錄「目前執行到哪裡、等一下要跳回哪裡」。可以想像成一疊盤子：

```
呼叫 square(5)  → 疊上一個新盤子（記錄 main 目前執行到哪，並開始跑 square）
square 執行完畢 → 把最上面的盤子拿走，跳回 main 剛剛記錄的位置
```

如果 method 裡面又呼叫別的 method（例如 A 呼叫 B，B 又呼叫 C），盤子會一層一層疊上去，執行完再一層一層收回來。

## Method Overloading（方法多載）

Overloading 是指：**同一個 class 裡面，可以有好幾個「名稱相同」的 method，只要它們的參數不一樣（型態、數量、順序不同）**，Java 就能分辨要呼叫哪一個。


| 改變的地方 | 算 Overloading 嗎 |
|---|---|
| 參數數量不同 | ✅ 是 |
| 參數型態不同 | ✅ 是 |
| 參數順序不同（型態不同時） | ✅ 是 |
| 只有 method 名稱不同 | ❌ 不是 Overloading，是兩個獨立的 method |
| 只有回傳型態不同，參數完全一樣 | ❌ 不行，會編譯錯誤 |

> Java 判斷要呼叫哪個 method，看的是**參數列表（型態、數量、順序）**，不是回傳型態。

## Array 陣列

陣列是一個可以**存放多個同型態資料**的容器，每個資料有自己的**索引（index）**，索引從 **0** 開始算。

### 宣告與建立

```java
// 方法一：直接給初始值
int[] scores = {90, 85, 78, 92, 60};

// 方法二：先宣告長度，之後再填值
int[] scores2 = new int[5]; // 預設值都是 0
scores2[0] = 90;
```

### 索引（Index）：陣列的「門牌號碼」

```
索引:   0    1    2    3    4
陣列: [90,  85,  78,  92,  60]
```

### `.length`：取得陣列長度

```java
System.out.println(scores.length); // 5
```

### 常見陷阱：索引超出範圍

陣列長度是 N，合法索引永遠是 `0` 到 `N-1`，存取超出範圍會拋出 `ArrayIndexOutOfBoundsException`，程式直接當掉。

### 用 for 迴圈遍歷陣列

**一般 for 迴圈搭配索引**（可以拿到索引位置）：

```java
for (int i = 0; i < scores.length; i++) {
    System.out.println("第 " + (i + 1) + " 筆: " + scores[i]);
}
```

**加強版 for 迴圈（for-each）**（更簡潔，但拿不到索引）：

```java
for (int score : scores) {
    System.out.println(score);
}
```

## 二維陣列

方法一：直接給初始值
```java
int[][] scores = {
    {90, 85, 78},  // 第 0 列
    {88, 76, 95},  // 第 1 列
    {70, 82, 91}   // 第 2 列
};
```

方法二：先宣告大小，之後再填值
```java
int[][] grid = new int[3][4]; // 3 列、4 欄，預設值都是 0
grid[0][0] = 1;
grid[1][2] = 5;
```

索引：兩個維度

存取二維陣列的元素需要兩個索引：`陣列[列索引][欄索引]`
